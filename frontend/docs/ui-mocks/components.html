      Feedback and overlays

      Messages that confirm, warn or ask. Overlays use the native dialog element: Escape closes them and focus returns to the button that opened them.

      Alerts

      Alert, dismissible and static

      Summary updated

      The patient summary was refreshed after the latest note.

      Note not saved

      The connection dropped. Your text is still in the editor.

      Toast

      Toast (Sonner in shadcn). Announced politely. Hovering or focusing pauses it.

      Toasts confirm a finished action. They hide after six seconds and can be dismissed sooner.

      Confirmation dialog

      AlertDialog. Focus starts on Cancel, the safe choice.

      The button names the action. Nothing is deleted in this preview.

      Full-screen overlay

      Dialog, full screen. Used instead of a side drawer.

      The page behind is blurred. On phones the overlay fills the screen. Its header compacts as you scroll.
